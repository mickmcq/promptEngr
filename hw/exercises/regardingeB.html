Folks -

I know that many of you are still struggling with exercise B. That’s actually a good thing, believe it or not. There are two reasons for this.

First, exercise B is intended to be much harder than exercise A. It’s an exercise that LLMs may struggle with, so you have to think about it. It’s not like you can just give a prompt and get the right answer.

Second, you are developing a skill that will be useful to you in the future. You are learning how to coax an LLM into doing something that is hard for it to do. As you know, LLMs are reaching into more and more areas of human activity. The skill you are learning will help you use LLMs for more purposes.

Here are some things you can do to help you with exercise B.

Be specific

Some of you have asked for help and given very vague information about what you are doing. That suggests to me that you may be giving vague instructions to the LLM. You need to be specific.

Break the problem down

Some of you have shown a single prompt to do the whole job. That probably won’t work. For example, I have found that, if I give an LLM a bibliography in APA format, it can easily convert it to BibTeX format. So just getting the information that will go into the BibTeX file can be one or more separate steps.

Control the temperature

Some of you are experiencing hallucinations. I expect that. There are parameters you can control in any LLM to reduce hallucinations, such as temperature. We discussed these parameters two weeks ago and you need to manipulate them.

Overreliance on vanilla ChatGPT

With a paid subscription, you can use many different chatbots, including some designed for scholarly work. Try them out.

Don’t use screenshots

Some students have shared screenshots of the LLM output. This will not serve you well. Instead, copy and paste the output into your document, surrounded by triple backticks. This will make it easier for me to read and easier for you to search and edit later, as you reuse your work. It will also shrink the size of the file you submit and reduce the need to put in directives like embed resources: true in the YAML header.

Reduce the use of adjectives

Some students have used adjectives like “renowned journals” and this is not helpful. Instead, you can use the name of the journal or specific conference.

Reuse output

When you get one article, that article has a reference section that may be be useful for a later prompt. You can actually use pdftotext or similar software to extract the reference list from the PDF and use it as input to a later prompt.

Give the specific model you are using

Some students have just said “ChatGPT” when I ask them what model they are using. This is not helpful. I need to know the specific model you are using, such as gpt-3.5-turbo or gpt-4o. Of course, the recently released o3-mini has features that you can exploit. Different models have different capabilities and will give different results.

Above all, document

You need to document what you are doing. If you are not successful, your documentation of what you have tried will go a long way to a good grade. This assumes your documentation is clear and complete.

Ask for help, right to the last minute

I will be available to answer emails today and tonight up to the deadline (with occasionally a delay). Don’t be afraid to ask for help but be sure you have read this message and, when you ask for help, be specific about what you have tried and what you need help with.
